# Verificador do Laudo

Versão atual: **1.0.0** (04/10/2026).

Abrir no navegador (Chrome ou Edge): https://atiladivi.github.io/verificador/

Confere um laudo entregue pelo formulário Laudo de Avaliação:

- **Código de verificação:** calculado dos dados do laudo e comparado com o rodapé das páginas, as propriedades do PDF e a revisão.
- **Versão do formulário** usada no laudo e a situação (vigente ou desatualizada).
- **Arquivo do modelo de inferência** (.sda / .tsr): confere e salva com o nome original.

Arquivo único (`index.html`). O PDF é lido no computador de quem usa; nada é enviado e o arquivo não é alterado. Lê também o laudo assinado na plataforma de assinatura.
